# Hi, I'm Alex

I build small, local-first tools for AI-assisted development and OpenBSD.

The common idea behind these projects is simple: keep important state outside
the model. User identity, permissions, file locations, business data, and
session progress should remain explicit, inspectable, and under human control.

## Selected projects

- **[agent-checkpoint](https://github.com/hotalexnet/agent-checkpoint)**
  Repo-local checkpoints for coding agents. Save goals, decisions, files,
  verification, and next steps as Markdown, then resume after an interruption
  or model switch.

- **[decision-review](https://github.com/hotalexnet/decision-review)**
  A skill for auditing decisions: extract the premises, check the evidence,
  identify uncertainty, and return falsifiable criteria instead of a rushed
  recommendation.

- **[office-reporting-mcp-kit](https://github.com/hotalexnet/office-reporting-mcp-kit)**
  MCP contracts and adapters for Office report generation. Identity,
  authorization, business data, template paths, and delivery confirmation stay
  under backend control.

- **[pdf-recognition-core](https://github.com/hotalexnet/pdf-recognition-core)**
  Local PDF recognition that returns document structure, semantic chunks,
  formula hints, and OCR fallback for scanned pages.

# 你好，我是 Alex

我主要做面向 AI 辅助开发和 OpenBSD 的小型、本地优先工具。

这些项目有一个共同原则：重要状态不要交给模型保存。用户身份、权限、文件
位置、业务数据和会话进度，都应该明确、可检查，并由人控制。

## 主要项目

- **[agent-checkpoint](https://github.com/hotalexnet/agent-checkpoint)**
  面向编码 Agent 的仓库内 checkpoint 工具。把目标、决策、文件、验证结果和
  下一步保存为 Markdown，方便会话中断或切换模型后继续工作。

- **[decision-review](https://github.com/hotalexnet/decision-review)**
  用于审查决定的 skill：提取前提、核对证据、识别不确定性，并给出可证伪的
  判据，而不是仓促地下结论。

- **[office-reporting-mcp-kit](https://github.com/hotalexnet/office-reporting-mcp-kit)**
  面向 Office 报表生成的 MCP 契约和适配器。身份、授权、业务数据、模板路径
  和投递确认由后端控制。

- **[pdf-recognition-core](https://github.com/hotalexnet/pdf-recognition-core)**
  本地 PDF 识别工具，输出文档结构、语义分块和公式线索，扫描件使用 OCR 兜底。
