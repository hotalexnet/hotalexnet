### Hi, I'm Alex

Most of my repos do the same thing in different places: **keep an AI agent from being the
source of truth**. Who the user is, what they're allowed to do, where files live, and what
we were doing last session all stay outside the model.

What I publish tends to be small, local-first, and documented in both English and Chinese.

---

#### What I'm working on

**[agent-checkpoint](https://github.com/hotalexnet/agent-checkpoint)** · ⭐13
Repo-local checkpoint and resume skills for coding agents. One agent writes the handoff as
plain markdown, another picks it up — so state survives model switches, restarts, and
machine changes instead of living in chat history.

**[decision-review](https://github.com/hotalexnet/decision-review)**
A skill that audits a decision instead of making it. Extracts the premises, checks who
actually said what, grades the evidence, and hands back falsifiable criteria rather than a
confident recommendation.

**[office-reporting-mcp-kit](https://github.com/hotalexnet/office-reporting-mcp-kit)**
MCP contracts and adapter protocols for Office report generation where identity,
authorization, business data, template paths, and delivery confirmation all stay under
backend control — the model never gets to decide who you are.

**[pdf-recognition-core](https://github.com/hotalexnet/pdf-recognition-core)**
Local PDF recognition that returns structure, not just text: sections, semantic chunks,
formula hints, and OCR fallback for scanned pages. No service stack attached.

### 你好，我是 Alex

我这些仓库做的其实是同一件事，只是落在不同的地方：**别让 AI agent 成为真相的来源**。
用户是谁、他有权做什么、文件在哪、上次做到哪儿了——这些都留在模型之外。

我发布的东西一般有三个特点：小、本地优先、中英双语文档。

#### 在做的事

**[agent-checkpoint](https://github.com/hotalexnet/agent-checkpoint)** · ⭐13
给编码 agent 用的仓库内检查点与恢复技能。一个 agent 用纯 markdown 写下交接，
另一个接着做——状态因此能跨模型切换、重启和换机器存活，而不是困在聊天记录里。

**[decision-review](https://github.com/hotalexnet/decision-review)**
审查一个决定、而不是替你做决定。把前提挖出来，查清谁说了什么，给证据分级，
最后交出可证伪的判据，而不是一个自信的推荐。

**[office-reporting-mcp-kit](https://github.com/hotalexnet/office-reporting-mcp-kit)**
面向 Office 报表生成的 MCP 契约与适配器协议。身份、授权、业务数据、模板路径、
投递确认全部由后端掌控——模型无权决定"你是谁"。

**[pdf-recognition-core](https://github.com/hotalexnet/pdf-recognition-core)**
本地 PDF 识别，返回结构而不只是文本：章节、语义分块、公式线索，扫描件走 OCR 兜底。
不绑定任何服务栈。
